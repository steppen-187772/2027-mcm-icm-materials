# O/F 奖论文获取、阅读与案例拆解

## 一、官方论文和结果入口

- [COMAP 历年赛题与结果](https://www.contest.comap.com/undergraduate/contests/mcm/previous-contests.php)
- [2026 各题结果和 O 奖论文入口](https://www.contest.comap.com/undergraduate/contests/mcm/contests/2026/results/)
- [2025 各题结果和 O 奖论文入口](https://www.contest.comap.com/undergraduate/contests/mcm/contests/2025/results/)
- [MATHmodels 官方论文库](https://www.mathmodels.org/)

官方 Results Report 主要是：

- 新闻稿；
- O/F/M/H/S 等奖名单；
- 所有参赛队伍的结果；
- 部分冠名奖信息。

它通常不是论文正文。完整 O 奖论文入口在结果页和 MATHmodels，部分内容需要会员权限。

## 二、F 奖论文的实际情况

COMAP 稳定公开 O 奖论文，但没有发现完整、官方、统一的 F 奖论文库。

F 奖公开内容通常取决于：

- 队伍是否自行发布；
- 学校或指导老师是否公开；
- 团队成员是否在 GitHub 或个人网站分享；
- 是否进入 UMAP Journal 或课程资料。

因此，看到“F 奖论文合集”时要检查：

1. 控制号；
2. 年份；
3. 题号；
4. 页眉奖项；
5. 是否只是 M/H 奖或参赛者自写参考论文；
6. 是否有 COMAP 结果页对应记录。

## 四、O 奖论文精读方法

每篇至少拆成六个部分：

1. 摘要如何概括每一问；
2. 问题分析如何把题面转成建模任务；
3. 假设与符号怎样支撑模型；
4. 多个问题之间如何递进；
5. 结果、误差、灵敏度和结论怎样闭环；
6. 图表承担什么说服任务。

## 六、阅读之后的产出

读完一篇 O 奖论文，必须形成自己的东西：

- 一张论文结构图；
- 一张模型关系图；
- 一份摘要结构清单；
- 一段结果分析改写；
- 一张可复用图表；
- 一个能在 Python 中运行的模型或算法；
- 一条“这篇论文为什么能拿 O 奖”的证据。

只看 PDF 不做拆解，不能转化为比赛能力。
