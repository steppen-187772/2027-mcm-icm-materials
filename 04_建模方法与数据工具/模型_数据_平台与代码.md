# 模型、算法、数据处理与模型平台

## 一、按问题结构选模型

不要先选模型再找题目。先判断问题的输出形式、约束、数据和时间要求。

| 问题结构 | 候选方法 | 适合验证 |
|---|---|---|
| 连续变化、变化率 | 微分方程、差分方程、状态空间 | 数值稳定性、边界、参数灵敏度 |
| 离散决策、排序和路径 | 图论、整数规划、动态规划 | 小规模穷举、约束检查 |
| 多目标资源分配 | 线性/非线性/多目标优化、启发式算法 | Pareto 前沿、可行性和权重灵敏度 |
| 预测 | 回归、ARIMA、指数平滑、树模型、神经网络 | 时间切分验证、误差和残差 |
| 分类与聚类 | 逻辑回归、树模型、SVM、K-Means | 交叉验证、类别不平衡、可解释性 |
| 评价与排名 | AHP、熵权、TOPSIS、模糊评价 | 权重改变后的排序稳定性 |
| 网络 | 中心性、社区发现、最短路径、网络优化 | 随机删边、节点扰动 |
| 政策情景 | 指标体系、系统动力学、情景分析、Agent 或仿真 | 情景对比和参数不确定性 |

### 模型选择的最低要求

至少保留两个候选模型，并比较：

- 输入和输出；
- 关键假设；
- 参数来源；
- 计算时间；
- 可解释性；
- 能否验证；
- 失败条件；
- 与简单基线相比的改进。

不要用复杂模型掩盖缺失数据和不可验证的假设。

## 二、Python 基础工具链

### 数据处理

- Pandas：表格读取、清洗、合并和时间索引；
- Polars：大表和高速处理；
- NumPy：数组与数值计算；
- SciPy：优化、积分、插值和稀疏矩阵。

### 统计与机器学习

- statsmodels：回归、时间序列和统计推断；
- scikit-learn：预处理、交叉验证、树模型、聚类和分类；
- PyMC：贝叶斯模型和不确定性；
- SHAP：特征贡献和可解释性。

### 优化、网络和仿真

- SciPy optimize：连续优化与约束；
- Pyomo 或 OR-Tools：数学规划和组合优化；
- pymoo：多目标优化；
- NetworkX：图、路径、中心性和社区；
- SimPy：排队和离散事件仿真。

### 符号和数学检查

- SymPy：代数、微积分和符号推导；
- Matplotlib：所有最终数据图；
- Seaborn：探索性统计图；
- Plotly：交互检查，不直接作为论文最终图。

对应 Codex Skill：

```text
$exploratory-data-analysis
$statistical-analysis
$statsmodels
$scikit-learn
$pymc
$pymoo
$networkx
$simpy
$sympy
$scientific-visualization
$matplotlib
$seaborn
```

### 数据使用原则

1. 优先官方第一手数据；
2. Kaggle 转载数据要继续寻找原始机构；
3. 记录下载日期、版本、单位和许可证；
4. 不将缺失值静默删除；
5. 数据泄漏必须在建模前检查；
6. 图表和论文中要引用数据来源。

## 六、数据和模型验证

### 数值模型

- 单位检查；
- 边界和极端情况；
- 小规模穷举；
- 改变步长和时间分辨率；
- 参数扰动。

### 统计与机器学习

- 明确训练/验证划分；
- 时间序列按时间切分；
- 聚类或特征选择要在训练集内完成；
- 处理类别不平衡；
- 报告基线；
- 检查残差；
- 避免测试集泄漏。

### 优化模型

- 检查约束是否实际生效；
- 用小规模案例验证最优性；
- 多个随机种子；
- 比较不同初始解；
- 检查不可行时的替代方案。

### 网络模型

- 检查网络构建规则；
- 做随机删边或节点扰动；
- 解释中心性和路径的实际含义；
- 不用漂亮网络图代替模型验证。

## 七、最终提交给论文的结果

论文需要的不只是最好一个数值，而是：

- 基线；
- 改进；
- 验证；
- 误差；
- 灵敏度；
- 适用条件；
- 失败案例或限制；
- 实际建议。

如果这些内容缺失，再复杂的模型也很难形成完整获奖论文。
