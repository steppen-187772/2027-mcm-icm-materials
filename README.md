## 先看这几个结论

1. **2027 年比赛时间以 COMAP 官方为准。** 美国东部时间 2027-01-28 17:00 开始，2027-02-01 20:00 结束；换算为北京时间是 2027-01-29 06:00 至 2027-02-02 09:00，论文提交截止为北京时间 2027-02-02 10:00。
2. **2027 年沿用 25 页总限制。** 摘要页、目录、正文、参考文献、附录、代码和题目要求的其他材料都计入。AI 使用报告附在 25 页正文之后，不计入 25 页。
3. **使用 AI、翻译软件、数学软件、代码补全等工具需要披露。** 必须在正文内引用、参考文献中列明，并附 `Report on Use of AI Tools`；不得把 AI 生成整篇论文后直接作为团队成果提交。
4. **官方只稳定公开 Outstanding（O 奖）论文。** 2025、2026 结果页可以查看各题 O/F 获奖名单，完整 O 奖论文入口在 MATHmodels.org，论文正文通常要求会员权限。没有发现可靠、完整、官方的 F 奖论文公开库；知乎上的 F 奖内容主要是获奖者经验帖。
5. **知乎的年份性文章不能替代当年规则。** 报名教程、页数、提交方式等可能过时，甚至存在机构转述错误。比赛前必须以 COMAP 当年 `Contest Rules, Registration and Instructions` 为准。

## 推荐阅读顺序

1. 先读本文件下面的“2027 关键规则速查”。
2. 再读知乎资料笔记中的“必读 8 篇”，建立比赛全貌。
3. 选 2 个目标题型，按题型去读 2025、2026 真题与对应的 O 奖结果页。
4. 至少完整精读 2 篇近年 O 奖论文，重点拆摘要、问题分析、模型衔接、结果讨论、灵敏度分析和图表。
5. 做完一次限时模拟后，再回看论文写作规范和 O 奖复盘。

## 2027 关键规则速查

以下信息于 2026-11-16 从 COMAP 官方竞赛说明页核对。

| 项目 | 官方规则 |
|---|---|
| 报名费 | 每队 100 美元，不退 |
| 队伍规模 | 1 至 3 人 |
| 学校限制 | 所有队员必须在同一所学校/机构注册 |
| 指导老师 | 可以是本校教师、职员或学生，负责注册和提交事务 |
| 官方报名截止 | 美东时间 2027-01-28 15:00 |
| 比赛开始 | 美东时间 2027-01-28 17:00 |
| 比赛结束 | 美东时间 2027-02-01 20:00 |
| 提交截止 | 美东时间 2027-02-01 21:00 |
| 成绩公布 | 2027-05-08 |
| 题号 | MCM：A、B、C；ICM：D、E、F，只能选一题提交 |
| 文件 | 英文 Adobe PDF，至少 12 号可读字体，US Letter 或 A4 |
| 页数 | 25 页总上限；摘要、目录、正文、参考文献、附录、代码均计入 |
| 匿名 | 每页只显示队伍控制号和页码，不得出现姓名、学校或地区等身份信息 |
| AI | 允许负责任使用；必须引用、列入参考文献，并在正文后附 AI 使用报告 |
| 提交 | 使用新的在线表单，需要队伍控制号、指导老师 ID 和选题 |
