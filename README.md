## 推荐使用顺序

1. 先读规则，明确比赛时间和提交限制；
2. 根据团队能力缩小到 1 个主攻题型和 1 个备选题型；
3. 用备赛路线建立团队分工和至少一次模拟；
4. 按题型学习模型、代码、数据和验证；
5. 精读 O 奖论文并练习摘要、结果图和灵敏度分析；
6. 固定 AI、论文、图表和 PPT 工作流；
7. 用真题完成一次全流程演练。
